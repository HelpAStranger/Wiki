MekaMiners Oasis

Modpack oficial focado em tecnologia, exploração e automação.

Requisito Obrigatório: Java 17

Para jogar na Temporada 8, você deve ter o Java 17 instalado. Versões antigas (Java 8) ou muito recentes (Java 21+) podem causar falhas críticas ao iniciar o jogo.

Escolha sua plataforma preferida para baixar o modpack. Recomendamos o uso do CurseForge ou a instalação manual via DropBox para usuários do TLauncher.
